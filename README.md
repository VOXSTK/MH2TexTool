# MH2 Tex Tool

Инструмент для работы с файлами текстур `.tex` **PC-версии игры Manhunt 2** (Windows, контейнеры `TCDT` и `Z2HM`).

Работает с файлами игры прямо на ПК: открывает `.tex` из папок установленной Manhunt 2, показывает текстуры, экспортирует их в PNG/BMP и загружает изменённые обратно в `.tex` для дальнейшей замены в игре.

Инструмент написан **исключительно под PC-версию Manhunt 2** и тестировался **только на её файлах**. Консольные версии игры и другие проекты не поддерживаются и не проверялись.

Приложение на C# / .NET 8 (WinForms) с графическим интерфейсом и CLI-режимом: просмотр текстур внутри `.tex`, экспорт в PNG/BMP, импорт картинок обратно с пересборкой контейнера без потери остальных данных.

> Статус: ранняя версия (0.1.0), ориентирована на текстуры Manhunt 2.

## Возможности

- Открытие `.tex`-контейнеров (`TCDT`, `Z2HM` со сжатием zlib).
- Определение форматов DDS внутри контейнера (DXT1/DXT3/DXT5, RGBA, RGB и др.), мип-уровни, паддинги.
- Экспорт одной текстуры, выбранных или всех сразу — в PNG или 24-битный BMP.
- Импорт PNG/BMP/JPG/TGA/DDS обратно в текстуру с автоматическим ресайзом под оригинальный размер и перекодированием в нужный формат (BC1/BC2/BC3 через BCnEncoder.Net).
- Пакетная конвертация целых папок с текстурами (`--export-tree` / `--import-tree`).
- Round-trip самопроверка контейнера (`--selftest`): гарантирует, что «прочитать → собрать» даёт побайтово идентичный результат.
- Проверка целостности `.tex` (`--check`).

## Сборка

Нужен .NET SDK 8.0:

```powershell
git clone <repo-url>
cd MH2TexTool
dotnet build MH2TexTool.slnx -c Release
```

Готовый exe: `src/MH2TexTool/bin/Release/net8.0-windows/MH2TexTool.exe`.

## Использование (GUI)

Запуск без аргументов открывает окно редактора. Можно перетащить `.tex` в окно или передать путь аргументом:

```powershell
MH2TexTool.exe "C:\path\to\textures.tex"
```

Меню:

- **Файл** — открыть / сохранить как `.tex`;
- **Экспорт** — выбранные или все текстуры в папку (PNG/BMP);
- **Импорт** — папка с картинками → все или выбранные текстуры, сброс замен;
- **Инструменты** — пакетная конвертация папки в PNG/BMP;
- **Справка** — описание формата `.tex`.

## Использование (CLI)

Аргументы, начинающиеся с `--`, включают консольный режим. Лог всегда пишется в файл (`%TEMP%\MH2TexTool-cli.log` или путь из переменной `MH2_LOG`).

```powershell
MH2TexTool.exe --selftest  <file.tex>
MH2TexTool.exe --check     <file.tex>
MH2TexTool.exe --export    <file.tex> <folder> [png|bmp]
MH2TexTool.exe --import    <file.tex> <folder> <out.tex>
MH2TexTool.exe --export-tree <texRoot> <outRoot>
MH2TexTool.exe --import-tree <texRoot> <pngRoot> <outRoot>
```

`--export-tree` сохраняет структуру папок: `<outRoot>/<rel>/<tex>/<name>.png`.
`--import-tree` собирает новые `.tex` по той же схеме и кладёт их в `<outRoot>`.

## Python-утилиты

В `tools/` лежат вспомогательные скрипты для исследования формата (не нужны для работы приложения):

| Скрипт | Назначение |
| --- | --- |
| `parse_tex.py` | разбор заголовка контейнера и списка DDS |
| `dump_tex.py` | дамп структуры `.tex` |
| `analyze_tex.py` | анализ форматов и паддингов текстур |
| `walk.py` | обход дерева с текстурами |
| `check_all.py` | массовая проверка набора `.tex` |
| `validate.py` | валидация собранных файлов |

## Формат

Контейнер `Z2HM` — это тот же `TCDT` (или raw-набор DDS), упакованный zlib после 8-байтового заголовка. Внутри — дерево узлов с именами текстур; каждая текстура хранится как DDS-блок (заголовок + мипы). Редактор сохраняет исходную раскладку узлов, выравнивания и служебные поля, поэтому пересборка без изменений совпадает с оригиналом побайтово.
